# Larvyn

**The Laravel workbench.** Your Laravel apps, their dev services, terminals, data and AI coding agents in one native window, for Linux, macOS and Windows.

- **Dev stack**: one toggle each for `artisan serve`, Vite, queue/Horizon, scheduler, Pail, Reverb and Octane.
- **Parallel agents**: send one prompt to Claude Code, Codex, OpenCode, Antigravity CLI, Cursor Agent, Aider or Pi. Each agent works on its own branch in a git worktree; review the diffs and merge the winner.
- **Laravel tools**: routes, models, database, Tinker, tests, queues, logs, `.env`, Composer updates and audits, plus a Doctor that fixes setup problems.
- **Terminals**: real PTYs with tabs and splits that keep running across views and projects.

## Install

Linux and macOS:

```sh
curl -fsSL https://raw.githubusercontent.com/larvyn/releases/main/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/larvyn/releases/main/install.ps1 | iex
```

Larvyn updates itself after that.
